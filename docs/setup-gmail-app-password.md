# Gmail 앱 비밀번호 만들기 (소장님 직접 작업)

신청자 안내 메일을 `matt@deeptactlearning.com`에서 보내려면, 앱이 이 계정으로 메일을 보낼 권한이 필요합니다.
그 권한이 **앱 비밀번호**(16자리)입니다. 구글 계정 본인만 만들 수 있어서 제가 대신 못 합니다.

- 예상 시간: 3분
- 만든 비밀번호는 **채팅에 붙여넣지 마시고** 3단계의 파일에만 저장합니다.
- 그 뒤 Vercel 등록·재배포·시험 발송은 제가 합니다.

---

## 1단계 — 앱 비밀번호 화면 열기

1. 크롬에서 아래 주소를 엽니다.

```
https://myaccount.google.com/apppasswords
```

2. 화면 오른쪽 위 프로필이 **matt@deeptactlearning.com** 인지 확인합니다.
   개인 gmail 계정으로 열려 있으면 프로필을 눌러 matt 계정으로 바꿉니다.
3. 비밀번호를 다시 물으면 입력합니다.

> **"찾고 있는 설정을 사용할 수 없습니다"**가 뜨면 → 아래 「잘 안 될 때」 1·2번을 보세요.

## 2단계 — 비밀번호 만들기

1. **앱 이름** 칸에 아래 이름을 붙여넣습니다. (나중에 무엇에 쓰는 비밀번호인지 알아보기 위한 이름입니다)

```
인생관리AI앱 신청자 안내메일
```

2. **만들기**(Create)를 누릅니다.
3. 노란 상자에 `abcd efgh ijkl mnop` 형태의 **16자리**가 뜹니다.
   ⚠️ 이 창을 닫으면 다시 볼 수 없습니다. 바로 3단계로 갑니다.

## 3단계 — 파일에 저장

1. 키보드 `Windows키 + R` → 아래를 붙여넣고 **확인**.

```
notepad C:\runtime\secrets\led-with-ai_gmail.txt
```

2. "새 파일을 만드시겠습니까?"가 뜨면 **예**.
3. 2단계의 16자리를 그대로 붙여넣습니다. 띄어쓰기는 있어도 괜찮습니다(제가 지웁니다). **다른 글자는 넣지 않습니다.**
4. `Ctrl + S`로 저장하고 메모장을 닫습니다.
5. 구글 화면의 **완료**를 누릅니다.

## 마지막 — 확인

- 앱 비밀번호 화면 목록에 **인생관리AI앱 신청자 안내메일**이 보이면 성공입니다.
- 저에게 **「저장했어」**라고만 말씀해 주세요. 비밀번호 자체는 알려주지 마세요.

---

## 잘 안 될 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 1. "찾고 있는 설정을 사용할 수 없습니다" | 2단계 인증이 꺼져 있음 | 아래 주소에서 **2단계 인증**을 켠 뒤 1단계부터 다시 |
| 2. 2단계 인증이 켜져 있는데도 같은 문구 | 워크스페이스 관리자 설정이 앱 비밀번호를 막음 | 저에게 알려주세요. 관리 콘솔 설정 방법을 따로 드립니다 |
| 3. 16자리 창을 닫아버렸다 | 다시 볼 수 없음 | 목록에서 그 항목을 지우고(휴지통) 2단계부터 다시 |
| 4. 나중에 비밀번호가 유출된 것 같다 | — | 앱 비밀번호 목록에서 **인생관리AI앱 신청자 안내메일**을 지우면 즉시 무효. 저에게 알려주시면 새로 연결합니다 |

2단계 인증 설정 주소:

```
https://myaccount.google.com/signinoptions/twosv
```

막히면 **몇 단계에서 어떤 글자가 떴는지**만 알려주세요.
